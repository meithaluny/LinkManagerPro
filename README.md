# Link Manager Pro

أداة احترافية لإدارة روابط الصور وإعادة التوجيه مع دعم كامل لـ SSR و Open Graph

## المميزات

✅ إدارة كاملة للروابط (إنشاء، تعديل، حذف)
✅ تتبع النقرات والإحصائيات
✅ SSR كامل مع Open Graph meta tags
✅ دعم متعدد المتاجر (شي إن، تيمو، نون، أمازون)
✅ واجهة احترافية مع Bootstrap 5
✅ قاعدة بيانات SQLite

## المتطلبات

- .NET 9 SDK أو أحدث
- Visual Studio 2022 أو VS Code

## التثبيت والتشغيل

### 1. استعادة الحزم
\`\`\`bash
dotnet restore
\`\`\`

### 2. تشغيل التطبيق
\`\`\`bash
dotnet run
\`\`\`

الموقع سيكون متاحاً على: \`https://localhost:5001\`
